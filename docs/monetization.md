# Реклама и доход на сайте

Документ о том, что уже подготовлено в коде, когда подавать заявку в РСЯ
и как включить рекламный блок, когда его одобрят.

## Что уже готово

| Что | Где | Зачем |
|---|---|---|
| Политика обработки данных | `/privacy` | 152-ФЗ и обязательное требование модерации |
| Контакты | `/contacts` | Модерация проверяет, что за сайтом стоит живой владелец |
| Согласие на форме входа | экран «Регистрация» | Согласие должно быть видно до отправки формы |
| Слот рекламного блока | `/decks`, `/decks/{slug}` | Готовое место показа, выключено по умолчанию |

Реклама **не появляется** внутри тренировки: человек пришёл учить слова,
и баннер посреди карточки убивает возвращаемость — то есть сам продукт.

## Когда подавать заявку

В правилах РСЯ есть причины отказа, которые важнее всех остальных:

- «Сайт не набирает достаточного количества реальных посетителей»;
- «Сайт не демонстрирует достаточного вовлечения пользователей».

Оба означают **повторную подачу только через 30 дней**. Поэтому подаваться
следует не «как только сайт заработал», а когда есть хотя бы несколько сотен
визитов в месяц — тогда шанс пройти модерацию с первого раза заметно выше.

Модерация обычно занимает меньше суток. Блоки можно создавать сразу, но доход
начисляется только когда сайт в статусе **«Активно»**.

## Требования, которые проверяют

- сайт открывается, основные разделы работают (не 404/500);
- основной контент доступен **без регистрации** — у нас каталог открыт;
- на странице контакты и политика обработки данных;
- реклама не преобладает над контентом и не перекрывает его;
- контент не скопирован и не сгенерирован «для объёма»;
- нет запрещённых тематик (18+, казино, ставки и подобное).

## Как включить блок после одобрения

1. В [partner.yandex.ru](https://partner.yandex.ru): **Реклама на сайтах → Блоки →
   Добавить**, тип «Баннер», размер «Адаптивный». Скопировать идентификатор
   вида `R-A-1234567-1`.
2. В `.env` на сервере:

   ```
   ADS_ENABLED=true
   ADS_BLOCK_ID=R-A-1234567-1
   ```

3. Перезапустить API:

   ```bash
   cd /opt/english-trainer
   docker compose -f docker-compose.prod.yml up -d api
   ```

4. Проверить, что блок отдаётся:

   ```bash
   curl -sS https://englishrainer.site/decks | grep -c yandex_rtb
   ```

Высота места под блок зарезервирована заранее, поэтому появление баннера
не сдвигает текст — это важно и для оценки скорости страницы, и для человека,
который уже начал читать список слов.

Пока `ADS_ENABLED=false`, страницы не делают **ни одного** стороннего запроса:
ни контейнера, ни пустой рамки, ни загрузчика РСЯ.

## Сколько это приносит

Ориентир по образовательной аудитории РФ — 50–150 ₽ за 1000 просмотров
страницы (в зависимости от тематики и сезона).

| Просмотров в месяц | Доход |
|---|---|
| 1 000 | 50–150 ₽ |
| 10 000 | 500–1 500 ₽ |
| 100 000 | 5 000–15 000 ₽ |

Вывод: реклама становится заметной примерно от 100 тысяч просмотров в месяц.
До этого она смысла не имеет — ни финансового, ни продуктового.

## Что для этого проекта выгоднее

1. **Подписка Pro** — 299–499 ₽ в месяц. Конверсия 1–3% от активных
   пользователей; при 1000 активных это уже 3 000–15 000 ₽, то есть больше,
   чем реклама при том же трафике.
2. **Партнёрские программы курсов** — 300–1 500 ₽ за оплатившего. Аудитория
   совпадает идеально: человек уже учит слова и думает про курсы.
3. **Реклама РСЯ** — как добавка к контентным страницам, не как основа.
4. **Telegram-канал** — у проекта уже есть бот, это готовый канал дистрибуции.

## Юридическая часть

- **Договор с Яндексом** оформляется на самозанятого (НПД) или ИП. Выплаты
  без статуса возможны, но неудобны и с удержанием НДФЛ.
- **Маркировка рекламы (ОРД/ЕРИР)**: в РСЯ её берёт на себя Яндекс — отдельный
  договор с ОРД не нужен, пока реклама показывается только через сеть.
  Если начнёте продавать места напрямую — маркировка станет вашей задачей.
- **Персональные данные**: политика на `/privacy` уже есть, реквизиты оператора
  задаются в `.env` (`LEGAL_OPERATOR_NAME`, `LEGAL_OPERATOR_INN`,
  `LEGAL_CONTACT_EMAIL`). Пустое имя оставит нейтральную формулировку
  «администратор сайта EnglishTrainer» — для реальной публикации лучше
  указать статус и ИНН.
